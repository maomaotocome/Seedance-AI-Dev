# Seedance competitive redesign — approved prototype brief

## Outcome

Create three high-fidelity, interactive landing-page directions that can be compared before any production code is changed.

## Product truth

- Seedance AI is an independent service using third-party API access.
- The generator is the source of truth for available models, settings, and product credit cost.
- Concept imagery in these prototypes is labeled as an original direction study and is not presented as model output.
- The prototypes preserve English and Chinese copy parity.

## Shared visual system

- Director's Desk: projection black, warm studio paper, signal orange, timecode amber, restrained sage.
- Instrument Sans-led system stack, Newsreader-style editorial accents, monospaced operational data.
- Bright daylight media offsets the dark product surfaces. No neon, glow, WebGL, autoplay hero, or decorative gradient field.
- One primary action: start a shot. Advanced parameters are progressively disclosed.

## Directions

1. **Creator Theater (recommended)** — a compact creation entry beside a dominant, controllable media stage. It borrows the product-immediacy of Runway and Higgsfield without copying their visual language.
2. **Film Journal** — an editorial contact-sheet composition with a persistent creation strip. Strongest brand voice and narrative rhythm.
3. **Creative Control Room** — a professional dark workspace with media canvas, prompt command dock, and precise cost/state readouts. Strongest product feel.
